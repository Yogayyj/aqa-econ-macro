核心知识点（可直接用于授课）

1) 宏观目标与指标

关键词：GDP、Inflation、Unemployment、BOP、Growth

课堂重点：解释“目标之间可能冲突”，如控制通胀与促进增长的短期权衡。

2) AD / AS 模型

关键词：AD, SRAS, LRAS, output gap

课堂重点：学生需要能说清“曲线为什么移动”“均衡变化意味着什么”。

3) 通胀与失业

关键词：demand-pull, cost-push, cyclical, structural, Phillips Curve

课堂重点：区分成因并能对应政策工具，避免“只背定义”。

4) 宏观政策工具

关键词：Fiscal, Monetary, Supply-side

课堂重点：每种政策都讲“机制 + 时滞 + 副作用 + 评价条件”。

5) 国际经济联系

关键词：exchange rate, current account, competitiveness

课堂重点：汇率变化如何影响净出口、通胀与增长。

建议的单节课板书结构（可复制）
  1. 考试目标（本节要拿什么分）
  2. 概念框架（定义 + 图）
  3. 机制链条（A 导致 B，B 导致 C）
  4. 政策评估（短期/长期、条件、风险）
  5. 课堂练习（1道解释题 + 1道评估题）
