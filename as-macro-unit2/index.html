AS Macroeconomics（Unit 2）详细知识点总览

The national economy in a global environment

1) 宏观经济表现的衡量

  • 目标：growth、price stability、unemployment、current account balance。
  • 指标：Real GDP、GDP per capita、CPI、unemployment、productivity、BOP current account、index numbers。
  • Nominal vs Real data。

2) 宏观经济如何运行

  • Circular flow：Income = Output = Expenditure；injections/withdrawals。
  • AD/AS：AD, SRAS, LRAS, equilibrium, demand/supply shocks。
  • AD = C + I + G + X − M 及其影响因素。
  • Multiplier 过程与计算。
  • SRAS/LRAS 位移因素。

3) 宏观经济表现

  • Short-run/Long-run growth；economic cycle；output gap。
  • 失业：cyclical、structural、frictional、seasonal、underemployment。
  • Inflation/Deflation/Disinflation；demand-pull 与 cost-push。
  • Current account 组成与影响因素。

4) 宏观经济政策

  • Monetary policy：interest rates、money supply、QE、对 AD/通胀/失业/汇率影响。
  • Fiscal policy：government spending、taxation、budget balance、national debt。
  • Supply-side：education、infrastructure、deregulation、tax incentives、industrial policy。
  • 评价政策：时滞、传导机制、约束条件、副作用。
